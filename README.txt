拾光集 · 交付包
================

web/
  index.html   前台时间轴高保真原型（暗房主题：晾片展开、手势灯箱、
               双指缩放、拉灯换肤、开场动画、显影加载管线）
  admin.html   管理后台高保真原型（登录、节点管理、显影盘上传、
               拖拽排序、改注/封面、回收站、主题切换）

docs/
  AI实现提示词.md   交给编码 AI 的完整实现规格（Go 后端 + 两页前端对接）
  后端设计方案.md   人读版设计文档（架构、存储选型、数据模型、运维）

使用方法：
1. 新建代码仓库，把 web/ 两个文件放入项目 web/ 目录；
2. 将 docs/AI实现提示词.md 整份粘贴给编码 AI（如 Claude Code）开始实现；
3. 按提示词第十三节的 5 个里程碑逐步验收。
